# Quiz Game Application 🧠🎮

An interactive and engaging Quiz Game Application built as part of the **SkillCraft Technology** internship program (**Task 03**). This application presents users with various types of questions, collects their responses in real-time, evaluates their answers, and delivers a final performance score.

---

## 🚀 Features

*   **Dynamic Question Formats:** Supports a diverse range of question types to keep the quiz engaging:
    *   **Single Choice (MCQ):** Standard multiple-choice questions with one correct answer.
    *   **Multi-Select:** Questions where users must select all applicable correct answers.
    *   **Fill in the Blanks:** Text-based input matching for direct answers.
*   **Real-Time Interaction:** Immediate user input collection and seamless progression to the next question.
*   **Instant Evaluation:** Tracks correct and incorrect responses on the fly.
*   **Final Score Summary:** Displays a clear, breakdown summary of the user's total score at the end of the session.
